# Welcome to my application "MoWiki"!


## **Project objective:**
The user can find a particular film by the following criteria: film title, year of release and genre.

---

## **How to install database?**
To install a database for this application, you need to enter the following data:
- host 		(host='ip_host')
- user 		(user='username')
- password 	(password = 'password')

**Without this data, you will not be able to connect to the database.** 

---

## **How to run application?**
Download this git repository and by using PowerShell you should be in folder of project. Then you should type this stroke:
```shell
\.venv\Scripts\python.exe main.py
```
_p.s. in PowerShell you have to type with keyboard by entering of numbers or sometimes some words :)_
